El alojamiento de aplicaciones poco tiene que ver con el alojamiento web, y debido al alto nivel de especialización que requiere, podemos elegir entre una gran variedad de opciones y proveedores a la hora de buscar alojamiento de aplicaciones.

Estas opciones se reducen drásticamente a la hora de buscar alojamiento de aplicaciones, y las principales soluciones que encontraremos son: un servidor dedicado (con los costes que suponen), o un VPS (una máquina en Cloud).  
Soluciones válidas pero tampoco tan económicas cuando buscamos un mínimo de recursos para nuestra aplicación (RAM/CORES&CPU).

## Hosting de aplicaciones Java

En el caso de las aplicaciones Java, existe una alternativa de alojamiento desde hace muchos años. ANW proporciona alojamiento de aplicaciones Java utilizando plataformas diseñadas![Codigo Java Propietario Fjgb](./imagenes/hosting-java/Codigo_java_propietario_fjgb-300x169.jpg) específicamente para el despliegue de aplicaciones Java, incluyendo servidores de aplicaciones dedicados en un entorno compartido.  
Con las plataformas de alojamiento Java de ANW, usted obtiene un servidor de aplicaciones dedicado por el precio de un alojamiento compartido.

Por decirlo de otro modo, cada alojamiento tiene un servidor de aplicaciones completamente dedicado, lo que da al programador total libertad para personalizar el entorno del servidor porque no hay limitaciones ni restricciones al ser dedicado. Esto garantiza el buen funcionamiento de la aplicación.

### Software de gestión

ANW dispone de un software de gestión propio (desarrollado por ellos) que permite al cliente instalar y configurar el servidor de aplicaciones en cuestión de clics, con la opción de seleccionar uno de los siguientes servidores de aplicaciones: Tomcat, Glassfish/Payara o Wildfly.  
Además, el sistema incluye numerosas versiones de cada servidor de aplicaciones, así como diferentes versiones del JDK. Todo está ahí para cubrir cualquier circunstancia, y todo es cambiable en cuestión de segundos.

### RAM

Otra ventaja es la cantidad de RAM asignada a cada plan de alojamiento, así como la posibilidad de configurar el tipo de límite suave que ANW aplica a los límites de recursos. Esto significa que si una aplicación consume más RAM en un punto de carga, el  
servicio no se verá interrumpido ya que el sistema absorberá la carga.  
Asegura que la aplicación no parece verse perjudicada. Las plataformas de alojamiento JAVA incluyen 128 GB de RAM, lo que garantiza que siempre estén disponibles recursos frente a un muro de carga

### Energia

Un corte de energía, ya sea en VPS o en soluciones en la nube, provocará invariablemente el cese de las aplicaciones y la interrupción del servicio.  
Todo lo contrario que los planes de ANW para el alojamiento Java.
